## 13. október 2026 — prijatá pilotná mapa

Michal potvrdil lokálny návrh piatich štvrtí a desiatich budov vrátane hraníc širšej výrobnej zodpovednosti odpoveďou „ano sedi“. Identifikovateľné podklady zostávajú lokálne. Brána významového mapovania prvého projektu je splnená; používateľská skúška 3D prototypu ešte neprebehla.

## Platí pre ďalšiu prácu

- Funkčné štvrte a trvalé budovy; priečinky sú vstup pre návrh, nie automatická definícia architektúry.
- Používateľ potvrdí alebo opraví prvú mapu. Opravy žijú v RepoCity.
- Režim **Mesto** poskytuje pokojnú kulisu; **Prehľad** pridáva názvy, pozorované stavy a vzťahy na požiadanie.
- Karta budovy vysvetľuje účel bežným jazykom a uvádza zdroje.
- Denná prehliadka zmien vznikne po spoľahlivom zbere udalostí.
- Zjednodušenie a odstránenie nepotrebného kódu môžu znamenať užitočnú rekonštrukciu. Veľkosť nie je skóre kvality ani výkonu človeka.
- Čerstvosť dát, pokrytie histórie a neznáme stavy sú viditeľné.
- Prvý vizuálny pokus: približne **8–12 budov**, jedna grafická sada. Bohatá stavebnica, epochy a úplná časová os sú neskôr.
- Overenie reálneho projektu predchádza rozširovaniu grafickej stavebnice.
- GitHub neposkytuje úplný obraz lokálnej práce. Konkrétneho živého agenta zobrazíme iba s osobitným spoľahlivým zdrojom.
- Pilotná mapa a podrobnosti zdrojového projektu zostávajú lokálne. Verejné príklady sú syntetické.
- AI architekt prichádza po ustálení pravidiel a skladá schválené diely. Nie je zdrojom faktických udalostí.

## Schválené poradie

Pravidlá mesta → mapa reálneho projektu → malá vizuálna ukážka → GitHub iba na čítanie → pilot pri bežnej práci → rozšírenia podľa výsledku.

Podrobné pravidlá nižšie sú konkrétnym návrhom realizácie schváleného smeru; prijatie pilotnej mapy je zapísané vyššie, skúška bežiaceho prototypu ostáva samostatnou otvorenou bránou.
