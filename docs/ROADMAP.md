# Roadmap — proposed

## Phase 0: research and technical gates (now)
- Verify licenses and feasibility of imported 3D kits.
- Inventory reusable building parts, anchors, roads and rotations.
- Evaluate stable district layout and 3D performance constraints.
- Draft event schemas; separate fact states from cosmetic states.

## Phase 1: Building Factory
- Modular 3D pieces, sockets and metadata.
- Procedural building recipes.
- Geometry and compatibility checks.
- Classic theme visual consistency.

## Phase 2: Living District
- Parcels, street graph, district composition.
- 30–50 building demo, workers and visual activity.
- Seed determinism and immutable building identity.

## Phase 3: Timeline and simulated PRs
- Versioned event reducer.
- 20+ mock PR/check/release events.
- Scrubbable time axis with replay and reproducibility tests.

## Phase 4: Repository Mirror
- Read-only GitHub scanner/adapter.
- Semantic mapper from varied repository types; confidence/fallback.
- PR/CI/release status into temporary constructions and stable additions.
- Privacy, rate limits, caching and accurate agent identification.

## Phase 5: AI City Architect
- Constrained city-only layout and recipe proposals.
- Personalization by project architecture and verified milestones.
- Validation gates, cost budgets and saved artifact provenance.
- Rare landmark unlocks and four-epoch progression.

## Later
- Magic World, Orcs theme packs.
- Opt-in read-only local worktree / agent telemetry.
- City-to-city sharing and historical project tours.

**No milestone above authorizes a modification to the observed repository.** RepoCity's own development repo naturally contains its own code and design docs.
